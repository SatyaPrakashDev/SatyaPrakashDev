# 👨‍💻 About Me

Hi, I'm **Satya Prakash**, a **Frontend Developer** focused on building modern, responsive and user-friendly web applications.

My primary stack is **React.js, JavaScript, Tailwind CSS and Vite**, with backend development experience using **Node.js, Express.js and MongoDB**.

I enjoy converting real-world requirements into practical software systems, especially **ERP, management, booking and e-commerce applications**.

I focus on writing structured code, creating reusable components, integrating APIs and building interfaces that are easy to use and maintain.
